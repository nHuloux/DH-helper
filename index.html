Fichier xacro :

Un xacro est un modèle paramétrable : renseignez ses arguments (par exemple le modèle de bras et le nombre d'axes), puis lancez la conversion. Ouverture expérimentale : si elle échoue, convertissez le fichier en URDF avec xacro.

Chaînes sérielles à articulations rotoïdes et prismatiques. Les fichiers .xacro sont convertis dans le navigateur (expérimental). Les maillages sont retrouvés même avec des chemins package://… tant qu'ils sont dans le dossier ou le zip déposé.
